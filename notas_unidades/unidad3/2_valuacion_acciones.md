# Unidad 3 · Valuación de Acciones

**Mercados de Deuda y Capitales**, Licenciatura en Comercio y Finanzas Internacionales, Universidad Autónoma de Zacatecas

## Objetivo de la unidad

Que el estudiante calcule el valor de una acción con el modelo de descuento de dividendos a partir de su información financiera, para decidir si su precio de mercado está caro o barato.

## Contenido

|     | Tema                              | Qué cubre                                                                                          |
| --- | --------------------------------- | -------------------------------------------------------------------------------------------------- |
| I   | De un bono a una acción           | Flujos inciertos y sin vencimiento: la acción como una perpetuidad de dividendos                   |
| II  | Modelo de descuento de dividendos | El valor de una acción con dividendos que crecen a tasa constante (modelo de Gordon)               |
| III | Los datos del reporte financiero  | De dónde salen el dividendo, su crecimiento y la tasa requerida en el reporte de una emisora       |
| IV  | Caro o barato                     | Comparar el valor calculado con el precio de mercado, y el múltiplo precio/utilidad como contraste |
